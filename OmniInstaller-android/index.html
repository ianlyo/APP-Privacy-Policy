Privacy Policy

Application: OmniInstaller
Effective Date: November 1, 2026

OmniInstaller is an open-source, local-only utility application. We do NOT collect, transmit, sell, or share any personal data or usage metrics with external servers or third parties.

1. Introduction

OmniInstaller is a standalone Android package installer and batch management tool designed to operate entirely on your device. We believe in complete transparency and respect for user privacy. This Privacy Policy outlines how OmniInstaller accesses and processes device data solely for providing app installation and management features.

2. Data Collection and Transmission

  • No Personal Information Collected: OmniInstaller does not require user accounts, email addresses, phone numbers, location data, or any personally identifiable information (PII).
  • No Telemetry / Analytics: OmniInstaller does not integrate any third-party tracking, analytics SDKs (e.g., Google Analytics, Firebase), or ad-serving networks.
  • No Remote Data Transfer: The application does not upload or transmit files, package metadata, or device information over the Internet. All file parsing, verification, and installations are handled strictly locally.

3. Android Permissions & Data Access

To perform its intended package management and installation functions, OmniInstaller requests specific device permissions. These permissions are used exclusively on-device:

  • REQUEST_INSTALL_PACKAGES
    Purpose: Required to trigger the Android system's standard package installer session for installing and updating APKs, split APK bundles (.apks, .apkm, .xapk), and apps chosen by the user.
  • MANAGE_EXTERNAL_STORAGE / Storage Permissions
    Purpose: Required to discover, inspect, and parse user-selected installation files (.apk, .apks, .apkm, .xapk), as well as to extract and place associated expansion files (.obb) into the system's /Android/obb/ folder as part of complete package installations. OmniInstaller only accesses files relevant to package installation tasks.
  • QUERY_ALL_PACKAGES
    Purpose: Used solely to inspect installed application details (such as current version code and version name) on your device to display upgrade/downgrade status diffs before proceeding with an installation.
  • FOREGROUND_SERVICE & POST_NOTIFICATIONS
    Purpose: Ensures that long-running batch installations and file extractions can run reliably without being abruptly killed by the operating system, while keeping the user informed of background task progress.
  • Elevated Execution (Shizuku & Root):
    Purpose: If granted voluntarily by the user, elevated privileges (via Shizuku or Root/libsu) are utilized strictly on-device to execute standard Android package installation commands (pm install) silently or with advanced options (such as downgrade flags). No data is exfiltrated or modified outside of explicit user requests.

4. Third-Party Services

OmniInstaller does not employ any third-party APIs, advertising networks, or external cloud storage providers. It operates as a fully offline and self-contained utility.

5. Security

Because all operations take place strictly within the sandboxed and local environment of your Android device, your files and personal data never leave your control. As an open-source project, our code is publicly auditable.

6. Children's Privacy

OmniInstaller does not knowingly collect or solicit any personal information from children under the age of 13.
